# 修仙世界模拟器

用手写神经网络（Handwired）规则守护网文战力体系 —— 写一千章也不吃书。

A xianxia cultivation world simulator: realm ladder, character roster with auto power ranking, battle verification （顺理成章 / 勉强成立 / 战力崩坏）, breakthrough simulation, and sect accounting. The battle rules are also implemented as a hand-wired neural network (ReLU + hand-written weights), toggleable in the UI.

- 在线体验：开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/xianxia-world-simulator/`
- 纯静态单文件，无需服务器
